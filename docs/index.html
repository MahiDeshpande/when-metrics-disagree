01

What are we trying to do?

Build a universal translation table that maps abstract metric numbers (PSNR, SSIM, LPIPS, TPIPS) into intuitive perceptual quality tiers on a single 0–100% scale — so “0.12 LPIPS” and “27 dB” can finally be compared in the same sentence.

02

How is it done today, and what are the limits?

Researchers report raw, isolated numbers. But a 25 dB PSNR means nothing on its own — it behaves entirely differently under Gaussian blur than under Gaussian noise or a one-pixel shift. Comparing numbers across distortions walks you straight into alignment traps.

03

What is new in our approach?

A unified, multi-metric evaluation grid across 10 synthetic and spatial distortion models, combining classical math (PSNR, SSIM), deep CNN features (LPIPS-Alex/VGG), and vision-language semantic distance (TPIPS), with a data-driven mapping of every score to a shared quality tier.

1 · Introduction

The unreliability of metrics

Every image-generation, restoration, and compression paper ends with a table of numbers. Those numbers decide which model gets published, which checkpoint gets shipped, and which loss function gets used to train the next one. The uncomfortable truth is that image quality metrics fail silently. They never throw an exception; they just return a confident-looking float that may have nothing to do with what a person would see.

When a metric is used for evaluation, a silent failure misranks models. When it is used for training (as a loss or a reward), the optimizer happily exploits the blind spot — producing images that score well and look wrong. Either way, the problem is the same: we treat the numbers as if they carried meaning on their own.

The big idea

Assign concrete semantic meaning to numerical ranges. If every metric score can be translated into the same four perceptual tiers — Indistinguishable Slight Noticeable Heavy — then we can measure, distortion by distortion, when metrics agree, when they disagree, and which one is lying.

Meet the four metrics

PSNR

Higher is better

Peak Signal-to-Noise Ratio · dB

The strict pixel accountant. Averages squared per-pixel error and puts it on a log scale. Blind to where the error is and whether anyone could see it.

SSIM

Higher is better

Structural Similarity · 0–1

The local pattern matcher. Compares luminance, contrast, and structure in sliding windows. Still requires pixels to line up.

LPIPS

Lower is better

Learned Perceptual Similarity · AlexNet / VGG

The deep-feature critic. Distances between CNN activations, calibrated on human judgments. We test both the AlexNet and VGG backbones.

TPIPS

Lower is better

Vision-language embedding distance

The semantic judge. Embeds both images with a vision-language model (Qwen3-VL-8B backbone) and measures how far apart they are in meaning.

2 · Related Work

The evolution of failure

The history of image quality metrics is a history of each generation patching the blind spots of the last — and introducing new ones.

  1. Classical

    PSNR / MSE

    Pure signal processing: treat every pixel as independent and equally important. Easy to compute and differentiate, which is why it never went away — and why its failure on perceptually irrelevant changes (shifts, global brightness) is so widespread.

  2. 2004

    SSIM Wang et al., 2004

    Built explicitly to fix PSNR’s blind spots by modelling the visual system’s sensitivity to structure rather than absolute error. A major step — but it still compares co-located windows, so geometric misalignment breaks it, and it is largely color-agnostic.

  3. 2018

    LPIPS Zhang et al., 2018

    “The Unreasonable Effectiveness of Deep Features as a Perceptual Metric.” Compares images in the feature space of pretrained CNNs (AlexNet, VGG), linearly calibrated on human two-alternative forced-choice judgments. Far more tolerant of small shifts — but the answer depends on the backbone you pick.

  4. 2026

    TPIPS Wang et al., 2026

    “The Many Senses of Visual Similarity.” Uses a vision-language model to compute an embedding distance that can be conditioned on which sense of similarity you care about (we use the overall factor). Excellent at semantic invariance; as we will see, sometimes too invariant to low-level damage.

3 · Methodology

The engineering process

Everything in this post was produced by a single, reproducible Jupyter pipeline (one notebook per reference image, all in the repository). The goal: make four fundamentally different metric families evaluate the exact same image pair under the exact same conditions.

1

Load & normalize

Resize to 512×512, RGB, float in [0, 1]

2

Distort

10 tests × 2–4 severity levels

3

Score

PSNR · SSIM · LPIPS-A/V · TPIPS on one pair

4

Translate

Map every score to a 0–100% quality tier

Hardware & environment

Fitting an 8B-parameter judge

Google Colab on NVIDIA L4 / A100 GPUs. LPIPS runs on the GPU in float32. The TPIPS embedder (Qwen3-VL-8B + LoRA, ~8.2B params) is loaded under a temporary half-precision default dtype — bfloat16 on CPU in the first run, float16 on CUDA in the dataset runs — with torchao installed for quantization kernels.

Metric extraction

One helper, every metric

A single compute_all_metrics() scores each pair: PSNR/SSIM on the raw float arrays, LPIPS on 1×3×H×W tensors rescaled to [−1, 1], TPIPS on 8-bit PIL images. plot_sweep_grid() renders the reference/distorted grid and the score table for each sweep.

Precision handling

No more dtype crashes

Half-precision defaults leaked into LPIPS and crashed it, so LPIPS is explicitly cast back to float32, and the TPIPS call is wrapped in torch.inference_mode() + torch.autocast to bridge 32-bit PIL preprocessing with the 16-bit model. Scores are pulled out with .item() and rounded.

The code

import gc, torch, lpips, tpips
from skimage.metrics import peak_signal_noise_ratio as compute_psnr
from skimage.metrics import structural_similarity as compute_ssim

gc.collect()
torch.cuda.empty_cache()
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# LPIPS: two CNN backbones on the GPU
lpips_alex = lpips.LPIPS(net="alex").to(device).eval()
lpips_vgg  = lpips.LPIPS(net="vgg").to(device).eval()

# TPIPS: ~8.2B-param Qwen3-VL embedder, loaded under a half-precision default
torch.set_default_dtype(torch.float16)      # bfloat16 when loading to CPU
tpips_model = tpips.load_model("embedding", device="cuda")
torch.set_default_dtype(torch.float32)      # restore for everything else
tpips_model.eval()
def compute_all_metrics(img_ref_np, img_dist_np, factor="overall"):
    """PSNR, SSIM, LPIPS (Alex & VGG) and TPIPS for one 512x512x3 pair in [0, 1]."""
    # 1. Classical metrics on raw float arrays
    score_psnr = compute_psnr(img_ref_np, img_dist_np, data_range=1.0)
    score_ssim = compute_ssim(img_ref_np, img_dist_np, channel_axis=2, data_range=1.0)

    # 2. LPIPS on [-1, 1] tensors, forced to float32 to avoid precision crashes
    to_t = lambda x: torch.tensor(x).permute(2, 0, 1).unsqueeze(0).float().to(device) * 2 - 1
    with torch.no_grad():
        lpips_alex.to(torch.float32); lpips_vgg.to(torch.float32)
        score_lpips_alex = lpips_alex(to_t(img_ref_np), to_t(img_dist_np)).item()
        score_lpips_vgg  = lpips_vgg(to_t(img_ref_np), to_t(img_dist_np)).item()

    # 3. TPIPS on 8-bit PIL images; autocast bridges fp32 preprocessing and the fp16 model
    ref_pil  = Image.fromarray((img_ref_np * 255).astype(np.uint8))
    dist_pil = Image.fromarray((img_dist_np * 255).astype(np.uint8))
    with torch.inference_mode(), torch.autocast(device_type="cuda", dtype=torch.float16):
        score_tpips = tpips_model.distance(ref_pil, dist_pil, factor=factor)
        if isinstance(score_tpips, torch.Tensor):
            score_tpips = score_tpips.item()

    return {
        "PSNR (↑)": round(score_psnr, 2),
        "SSIM (↑)": round(score_ssim, 4),
        "LPIPS-Alex (↓)": round(score_lpips_alex, 4),
        "LPIPS-VGG (↓)": round(score_lpips_vgg, 4),
        "TPIPS Distance (↓)": round(score_tpips, 4),
    }
def apply_gaussian_noise(img, sigma=10):
    return np.clip(img + np.random.normal(0, sigma / 255.0, img.shape), 0.0, 1.0)

def apply_gaussian_blur(img, radius=1):
    k = radius * 2 + 1
    return cv2.GaussianBlur(img, (k, k), 0)

def apply_translation(img, shift_pixels=2):
    rows, cols, _ = img.shape
    M = np.float32([[1, 0, shift_pixels], [0, 1, 0]])
    return cv2.warpAffine(img, M, (cols, rows))          # zero-padded boundary

def apply_crop_resize(img, crop_percent=0):
    h, w, _ = img.shape
    ch, cw = int(h * crop_percent / 100), int(w * crop_percent / 100)
    return cv2.resize(img[ch:h - ch, cw:w - cw], (w, h))

def apply_color_shift(img, shift_deg=0):
    hsv = cv2.cvtColor((img * 255).astype(np.uint8), cv2.COLOR_RGB2HSV)
    hsv[:, :, 0] = (hsv[:, :, 0].astype(int) + int(shift_deg / 2)) % 180
    return cv2.cvtColor(hsv, cv2.COLOR_HSV2RGB) / 255.0

# Every test runs through the same sweep helper:
df_shift = plot_sweep_grid(img_ref, apply_translation, levels=[1, 2, 4, 8],
                           param_name="Shift (px)", exp_title="Spatial Translation")

5 · The Grand Synthesis

The Metric Translation Table

The translation starts from a tier reference distilled from the IQA literature: four perceptual bands, each with a score range per metric. We turn those bands into a continuous Perceptual Quality Index (PQI) by piecewise-linear interpolation, so every tier occupies exactly one quarter of the 0–100% scale. Then we apply it to every measurement we collected.

7 · Key Takeaways

What to do with all this

  1. Never report PSNR alone for anything geometric. A 1-pixel shift drops it to 24.6 dB (Noticeable) while LPIPS and TPIPS call the result Indistinguishable; a 1° rotation pushes it into Heavy while TPIPS still sees no visible change.
  2. A PSNR value is only meaningful within a distortion family. Noise PSNR barely varies across images (±0.4 dB at σ = 5), but blur PSNR swings by ±4.4 dB depending on content. “25 dB” is a different image every time.
  3. SSIM is nearly color-blind. Converting to grayscale or rotating hue by 60° still lands SSIM in the Slight tier; TPIPS correctly flags both as noticeable.
  4. TPIPS can be too forgiving of low-level damage. At σ = 40 noise, LPIPS-Alex is deep in the Heavy tier while TPIPS still says Slight — semantic invariance cuts both ways.
  5. Backbones matter. LPIPS-VGG is consistently harsher than LPIPS-Alex on geometric changes and JPEG; report which one you used.
  6. Use a panel, not a judge. Translate each metric to a shared scale and look at the spread: large disagreement is itself a signal that something about the distortion is exploiting a blind spot.

Limitations & next steps

The tier bands are literature heuristics, not yet fitted to human ratings; the next phase of this project (Human Perception Alignment) will calibrate them against human judgments. The dataset is 12 images at 512×512, a single random draw per noise level, and TPIPS is evaluated only with the overall factor. Iso-PSNR calibration, heatmap clustering, and rank-disagreement mining across larger datasets are on the roadmap.
